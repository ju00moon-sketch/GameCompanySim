# GameCompanySim 작업 현황판

https://ju00moon-sketch.github.io/GameCompanySim/

`index.html`은 자동 생성된다(현황 파일이 바뀌면 다시 게시). 기계용 요약은 `status.json`, 총괄 기록 원문은 `status.md`.

페이지는 같은 탐색 탭 다섯 개로 나뉜다.
- `index.html`: 작업 현황. 현재 세션, 대표 결정, 대기 항목, 오늘 결과.
- `qa.html`: 질의응답. 답변이 바뀌면 그 항목만 다시 안 읽음으로 표시한다. 읽음 기록은 이 브라우저에만 저장되고 다른 기기와 공유되지 않는다.
- `gallery.html`: Unity 게임 화면 캡처(16:9). 실제 데이터와 미리보기 데이터 표시는 각 그림에 유지한다.
- `art.html`: 검증용 아트 렌더. 비교판이 잘리지 않게 원래 비율로 보인다.
- `closed.html`: 완료. 보고를 마친 세션, 완료 작업, 성공과 따로 세는 실패·반환 기록, 종결된 결정·대기 항목.

탭은 실제 링크이며 키보드 Enter, 뒤로 가기, 직접 주소 열기를 지원한다. 열린 항목이 없으면 「모두 읽음」 단추와 안 읽음 배지를 그리지 않는다.

세션 수집 경계
- 이 프로젝트의 작업 공간과 실행(run)만 읽는다. 다른 프로젝트의 세션은 수집하지 않는다.
- 작업 목록은 전체 기록에서 담당·제목·상태만 남기고 지시 원문과 결과는 버린다. 터미널 식별자도 공개 파일에 쓰지 않는다.
- 보고를 마친 세션은 터미널 연결, 모든 열린 작업의 담당, 자기 열린 작업 0이 확인될 때만 완료로 옮긴다. 확인할 수 없으면 연결 끊김·확인 필요·상태 확인 필요로 현재 목록에 남기고, 조회에 실패하면 현황판에 보류 이유를 적는다(`status.json`의 `checks`).
- 원장에 담당자가 남지 않은 이전 작업은 '원장에 담당 기록 없음'으로 적는다.

결정 자료는 질문·추천 이유·대안·플레이 차이·구현 영향·결정 시점·숫자 상태의 7항목으로 표시한다. 선택은 한 번에 하나씩 묻는 개별 항목으로 올리고, 완료 항목은 `closed.html`로 분리한다.
