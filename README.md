# GameCompanySim 작업 현황판

https://ju00moon-sketch.github.io/GameCompanySim/

`index.html`은 자동 생성된다(현황 파일이 바뀌면 다시 게시). 기계용 요약은 `status.json`, 총괄 기록 원문은 `status.md`.

갤러리는 같은 탐색 탭을 가진 두 페이지로 나뉜다.
- `gallery.html`: Unity 게임 화면 캡처. 실제 데이터와 미리보기 데이터 표시는 각 그림에 유지한다.
- `art.html`: 검증용 아트 렌더. 게임 화면과 별도로 불러온다.

두 페이지는 현황판의 기존 색·글꼴을 사용하고 선택한 탭만 강조한다. 작은 화면에서도 비교 자료를 섞지 않고 탐색하도록 나눈 것이다. 탭은 실제 링크이며 키보드 Enter, 뒤로 가기, 직접 주소 열기를 지원한다.
