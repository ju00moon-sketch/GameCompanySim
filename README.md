# GameCompanySim 작업 현황판

https://ju00moon-sketch.github.io/GameCompanySim/

`index.html`은 자동 생성된다(현황 파일이 바뀌면 다시 게시). 기계용 요약은 `status.json`, 총괄 기록 원문은 `status.md`.

페이지는 같은 탐색 탭 네 개로 나뉜다.
- `index.html`: 작업 현황. 담당별 작업 현황(등록 세션 전체의 열린 Task·확인된 진행 기록·미완료 이정표), 현재 세션(등록 세션 전체), 대표 결정, 대기 항목, 오늘 결과. 대표님께 드리는 미답변 질문은 대표 결정 칸 한곳에만 둔다.
- `gallery.html`: Unity 게임 화면 캡처(16:9). 실제 데이터와 미리보기 데이터 표시는 각 그림에 유지한다.
- `art.html`: 검증용 아트 렌더. 비교판이 잘리지 않게 원래 비율로 보인다.
- `closed.html`: 완료. 완료 작업(Task), 목표 기록의 완료 이정표, 이후 결정으로 대체된 이정표, 성공과 따로 세는 실패·반환 기록, 답변으로 종결된 결정과 종결된 대기 항목. 세션은 이 탭으로 옮기지 않는다.

탭은 실제 링크이며 키보드 Enter, 뒤로 가기, 직접 주소 열기를 지원한다. 열린 항목이 없으면 「모두 읽음」 단추와 안 읽음 배지를 그리지 않는다. 읽음 표시는 이 브라우저에만 저장되는 표시이며 답변이나 승인이 아니다. 저장된 읽음 기록(`gcs-read-v1`)이 v1 읽음 맵(항목별 읽은 시각 또는 true)이 아니거나 깨져 있으면 오류 없이 안 읽음으로 시작하고, 읽음 기록은 사용자가 누를 때만 다시 저장한다.

담당별 작업 현황
- 등록 세션마다 카드 하나를 두고, 그 세션에 배정된 열린 Task와 담당이 적힌 미완료 이정표를 보여 준다. 배정이 없으면 '현재 배정 작업 없음 · 다음 배정 대기'로 남긴다.
- 이정표 담당은 목표 기록의 `who`와 그 근거 `who_src`로만 정한다. 담당이 적혀 있지 않거나 담당 세션이 없는 이정표, 담당 세션을 확인할 수 없는 열린 Task는 '담당 확인 필요'에 모으고 임의로 배정하거나 완료 처리하지 않는다.
- 완료 이정표는 완료 탭에서 원래 제목과 근거를 유지한다. 나중에 커밋·완료 보고와 대조해 완료로 옮긴 단계는 `done_src`에 완료 근거를 남긴다. 작업(Task) 실행 기록과 이정표는 출처와 단위가 달라 건수를 합치지 않는다.
- 이후 결정으로 전제가 바뀐 단계(`state: superseded`)는 작업 현황에서 빼고 완료 탭의 '대체된 이정표'에 대체 관계 메모와 함께 남긴다. 완료 건수에는 넣지 않는다.
- 담당과 근거가 있는 현재 상태(`work_notes`)는 해당 담당 카드에 '진행 기록'으로 붙인다. 아직 없는 결과물의 링크나 이미지 자리는 만들지 않는다.

세션 수집 경계
- 이 프로젝트의 작업 공간과 실행(run)만 읽는다. 다른 프로젝트의 세션은 수집하지 않는다.
- 작업 목록은 전체 기록에서 담당·제목·상태만 남기고 지시 원문과 결과는 버린다. 터미널 식별자도 공개 파일에 쓰지 않는다.
- 세션은 상태와 관계없이 모두 현재 세션에 표시한다. 마지막 보고를 마친 세션은 터미널 연결, 모든 열린 작업의 담당, 자기 열린 작업 0이 확인될 때만 '보고 완료·대기'로 표시하고, 확인할 수 없으면 연결 끊김·확인 필요·상태 확인 필요로 구분한다. 조회에 실패하면 현황판에 보류 이유를 적는다(`status.json`의 `checks`).
- `status.json`의 열린 Task에는 세션 식별자 `session_id`(터미널 식별자가 아닌 해시)를 붙이고, 담당 세션을 찾지 못하면 비워 둔다.
- 원장에 담당자가 남지 않은 이전 작업은 '원장에 담당 기록 없음'으로 적는다.

결정 자료는 질문·추천 이유·대안·플레이 차이·구현 영향·결정 시점·숫자 상태의 7항목으로 표시한다. 선택은 한 번에 하나씩 묻는 개별 항목으로 올리고, 대표가 실제로 답한 항목만 종결해 답변(`answer`)과 함께 `closed.html`로 옮긴다. 구체안이 없는 후속 세부는 결정 카드로 미리 올리지 않는다.

2026-11-08 확인: 360/390px 어두운 화면, 가로 태블릿 932×704 어두운 화면, 1280px 밝은 화면에서 담당별 작업 현황과 현재 세션이 등록 세션 11개 전체(누락·중복 0)를 보여 주고, 완료·대체된 이정표는 완료 탭에만 있으며, 탭 4개 모두 가로 넘침·콘솔 오류·실패 요청 0임을 실제 브라우저로 확인했다. 대표 결정은 실제 답변으로 종결한 항목만 완료 탭으로 옮기며, 화면의 읽음 표시를 모두 켜도 열림·종결 수는 바뀌지 않는다. 아트 비교판은 원래 비율로 보이고, 넓은 화면의 작업 현황 카드는 빈 줄이 생기지 않도록 세로 단으로 채운다. 좁은 화면에서는 제목/본문이 세로로 쌓이며 근거 링크와 탭의 클릭 높이는 최소 44px이다.
